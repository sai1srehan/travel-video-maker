# Privacy Policy: travel-video

travel-video is a personal automation tool. It is used only by the owner of this repository to upload
travel videos to the owner's own YouTube channel.

## What it accesses
- With the owner's permission (Google OAuth, scope `youtube.upload`), it uploads videos and thumbnails
  to the owner's YouTube channel.
- It does not read, collect or store data about any other person.

## What it stores
- The OAuth login token is stored privately as an encrypted GitHub Actions secret, used only to upload videos.
- No personal data is sold, shared or sent to third parties.

## Removing access
Access can be removed at any time at https://myaccount.google.com/permissions.

Open an issue in this GitHub repository.
